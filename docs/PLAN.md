# PWA 게임 + 5개 경매 사이트 연결

본 문서는 사용자 요청을 기준으로 적어다. 별도 짓GPT 지시문은 이 요청에 없었다.

## 5개 사이트

| 이름 | 역할 | 주소 | 연결 방식 |
| --- | --- | --- | --- |
| 법원경매정보 | 공식 법원 경매 | https://www.courtauction.go.kr/ | 외부 링크. 스크래핑 안 함 |
| 온비드 | 공매 | https://www.onbid.co.kr/ | 외부 링크. 공공데이터 API는 별도 |
| 지지옥션 | 유료 경매 정보 | https://www.ggi.co.kr/ | 외부 링크. 제휴 전 내용 가져오기 금지 |
| 탱크옥션 | 유료 경매 정보 | https://www.tankauction.com/ | 외부 링크 |
| 옥션원 | 유료 경매 정보 | https://www.auction1.co.kr/ | 외부 링크 |

이 다섯은 소개용이다. 각 사이트 회원 요금을 우리가 할인해 주지 않는다. 할인은 우리 앱 이용료다.

## 요금

기본료를 100으로 둔다.

- 사이트를 1개 선택할 때마다 우리 앱 요금 20% 할인.
- 5개를 모두 선택하면 20% x 5 = 100%. 사이트 연결 이용료는 0이 된다.
- 일정 이용은 무료. 무료 횟수를 넘기면 위 요금이 적용된다.
- AI를 쓸 때 과금이 더 내려간다. 사용자 자신의 AI 키를 쓰면 우리 AI 비용을 묻지 않으므로, AI 항목을 할인한다.
- 키는 저장하지 않는다. 요청을 통과시킬 때만 쓴다.

예시. 기본 10,000원.

- 선택 0개: 10,000원. 무료 횟수 안에서는 0원.
- 선택 1개: 8,000원.
- 선택 3개: 4,000원.
- 선택 5개: 0원.
- 여기서 내 AI를 켜면 AI 할증 요금을 또 빤다.

## 클릭 후 가입

1. 사용자가 사이트 카드 또는 게임 버튼을 누른다.
2. 세션이 없으면 외부 사이트로 바로 보내지 않는다.
3. 가입 화면을 띄운다. 이미 계정이 있으면 로그인.
4. 가입 또는 로그인이 끝나면 원래 누르려던 사이트를 연다.
5. 무료 횟수 안이면 결제 화면을 건너뛴다.

## PWA에서 연결하는 방법

사이트를 앱 안 iframe으로 넣지 않는다. 대부분은 프레임 차단이 걸려 있다.

하는 것:

- 우리 화면에서 사이트 소개 카드를 보여 준다.
- 가입 확인 후 `window.open(url)` 또는 `location.assign(url)` 로 새 탭에서 연다.
- 사건번호가 있으면 공식 검색 주소가 허용하는 경우에만 쿼리로 붙인다.
- 게임은 우리 PWA 안에서 돌린다. 낙찰가 빈칸 빙고, 대기 미니게임.
- 게임이 끝나면 같은 화면에서 5개 사이트 카드를 보여 준다.
- 서비스 워커는 우리 앱 껍데기만 캐시한다. 외부 사이트 페이지는 캐시하지 않는다.

하지 않는 것:

- 법원경매정보, 지지옥션, 탱크옥션, 옥션원, 온비드를 스크래핑하지 않는다.
- 사용자 아이디와 비밀번호를 받아 대신 로그인하지 않는다.
- 유료 사이트 내용을 우리 DB에 복사하지 않는다.

## 화면 흐름

1. 대기 화면에서 게임을 한다.
2. 게임 아래에 5개 사이트 카드가 있다.
3. 카드를 누른다.
4. 비로그인이면 가입을 요청한다.
5. 로그인 후, 무료 횟수가 남았는지 본다.
6. 남았으면 사이트를 연다. 없으면 할인된 요금을 보여 주고 결제를 묻는다.
7. 선택한 사이트 수와 AI 사용 여부로 요금을 계산한다.
