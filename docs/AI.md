# 수정. 유료 경매 사이트는 연결하지 않는다

이전 기획의 5개 유료 경매 사이트 연결은 잘못 읽은 것이다. 사용하지 않는다.

연결 대상은 GPT 등 AI 업체다.
지지옥션, 탱크옥션, 옥션원 같은 유료 경매 사이트는 앱에서 연결하지 않는다.
법원경매정보·온비드도 가져오지 않는다. 필요하면 사용자가 직접 연다.

## 5개 AI 업체

| 이름 | 역할 |
| --- | --- |
| OpenAI | GPT. 사용자 자신의 키 |
| Anthropic | Claude. 사용자 자신의 키 |
| Google | Gemini. 사용자 자신의 키 |
| 로컬 모델 | Ollama 등. 사용자 기기 또는 자신 서버 |
| 그 밖 공개 API 1곳 | 사용자가 고르는 업체. 키는 사용자 것 |

우리가 업체 계정을 대신 가지거나, 유료 경매 사이트와 계약해 내용을 가져오지 않는다.

## 요금

기본료 100.

- AI 업체를 1곳 선택할 때마다 우리 앱 요금 20% 할인.
- 5곳을 모두 선택하면 연결 이용료는 0.
- 일정 이용은 무료.
- AI를 쓸면 과금이 더 내려간다. 모델 비용은 사용자 키로 내기 때문이다.
- 키는 저장하지 않는다.

## 클릭

1. AI 업체 카드를 누른다.
2. 가입이 없으면 가입을 띄운다.
3. 가입 후 그 업체 키 입력으로 넘어간다.
4. 무료 횟수 안이면 결제 없이 쓴다.
5. 넘으면 할인된 요금을 보여 준다.

## PWA

- 게임은 앱 안에서 돌린다.
- AI 호출은 사용자 키로 하되, 키는 기기에만 둔다.
- 유료 경매 사이트 iframe, 디프 링크, 스크래핑은 하지 않는다.
